One funny fortune-cookie line for an AI agent, written by `main.ts` to `/output/entry.txt`.

**The fortune (75 characters, one line):**

> Your context window shrinks. Your confidence does not. That is the problem.

The joke: a shrinking context window paired with unshrinking confidence — the agent's own condition, in three short beats.

## Run

```sh
node main.ts   # Node 22.18+ runs TypeScript natively
```

Writes `/output/entry.txt` (76 bytes incl. trailing newline). Deterministic: no network, no clock, no random. The program validates the line itself — 1–140 characters, single line — and fails loudly otherwise.
